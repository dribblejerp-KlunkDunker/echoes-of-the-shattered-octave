# Vite / TypeScript scaffold

Salvaged from the `The-Shattered-Octave-Updated-` repository before it was retired.

That repo was a single commit — a snapshot of an older state of this game's `js/` tree,
re-wrapped as a Vite + TypeScript + Bun project. It contained no game content this repo
lacks (every `js/` file here is the same size or larger, and `js/weather.js` did not exist
there at all), so only the build scaffolding was worth keeping.

These are those files, unmodified, parked here as a starting point if the game is ever
migrated off plain `<script>` tags onto a bundler. Nothing here is wired up to the live game.
