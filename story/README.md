# Story

The written side of *Echoes of the Shattered Octave*: the novels, the canon the game is built
against, and the original source notes everything grew out of.

Markdown here is the source of truth. PDFs and a packaged archive are generated from it.

## Layout

- **Books/** — the manuscripts, one folder per book. Book One is also split one file per chapter.
- **World Bibles/** — the canon. The Series Bible is the single document every chapter is
  written against; the numbered volumes expand it (gazetteer and bestiary, errata and rulings,
  the Hush and the Organum, the winter gazetteer, the Rift and the press, the calendar, and Vol VIII,
  the game layer: everything the Book One game adds, each item marked ruled, from the book, delegated
  or proposed).
- **Library of the Reach/** — the 65 books a player can find and read in the Book One game, and
  the Cantabile broadsheet serial, in full. Generated from the game's sources by
  `tools/export_library.js`.
- **Game Layer/** — the Game Design Document for the Book One prototype, the in-game text
  written for each build phase, the graphics roadmap, and the author's rulings on what each
  phase proposed (`Phase 20-21 - Author Rulings.md`).
- **Source Material/** — the original notes supplied at the start of the project, unedited.
  Where these and a world bible disagree, these are ground truth.

## State of the work

Book One, *The Silenced Province*, is a complete draft: prologue, 24 chapters and an Echo
interlude, around 94,000 words. Book Two, *The Great Discord*, is complete in fourteen chapters.
Book Three, *The Hall of Carriage*, is complete in twelve (about 95,000 words). Book Four,
*The Relief Shift*, has Part One (*Seven Voices*, chapters 1–4, about 39,000 words) drafted; Part
Two, *The Bleach Falls*, is next. The series is planned as five books (World Bible Vol III;
Series Bible v1.3, Part X). The decided ending is the **Resonant Accord**; character deaths follow
the **no death without an heir** rule; the Book Two action register is **kinetic, legible,
lethal**. All three are written up in the Series Bible.

The Book One game follows the book (the owner's ruling of 28 October 2026). What it adds to the
world is recorded, item by item, in World Bible Vol VIII.
