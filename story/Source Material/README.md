# Source Material

The original files supplied at the start of the project, preserved unedited (bar a title header on
each, and one stray upload token stripped from file 02). Everything in the Series Bible is
reconciled *from* these; when the bible and these disagree, these are the ground truth and the
bible's Canon Ledger should record the ruling.

- **01 - Master Reference Report** — the Solfeggio cosmology, the Harmonic Spire system, factions
  and character roster in report form.
- **02 - Master Narrative and Scripture** — the complete narrative bible, screenplay and dialogue
  corpus. Supplied as a single unbroken block of text; it reads rough but it is the richest source
  for voice and scene.
- **03 - Aethelgard Narrative Assets** — the four game deliverables: the Act I subway vault breach
  quest tree (JSON), the GDScript, the shaders, and the asset dossiers. This is the game-layer
  source, and Phase 6 is written against it.
- **04 - Asset Breakdown (short form)** — a shorter variant that overlaps 03. Kept for completeness.

A fifth upload was byte-identical to 02 and has not been duplicated here.

Also part of the source set, but living in the claude.ai project rather than this folder:
**Game Design Document — Book One Prototype** (Godot, Octopath Traveler style).
